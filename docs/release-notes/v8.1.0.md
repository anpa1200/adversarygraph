# AdversaryGraph 8.1.0 unpublished source candidate

Released source date: 2026-10-19.

## ATT&CK v20

Enterprise, Mobile and ICS imports support MITRE ATT&CK v20.0. Current views
exclude revoked and deprecated objects and relationships while raw history and
older catalog versions remain available. Reimporting an existing version
selects that snapshot atomically. MITRE ATLAS keeps its independent version
and source provenance.

Navigator exports use the selected ATT&CK version and preserve imported scores,
comments, disabled entries and tactic-specific technique annotations. Regression
coverage includes the official three-domain bundles, ICS version transitions,
relationships, Navigator round trips and STIX parsing.

## Evidence and workflow improvements

This stable line includes governed report promotion, source-bound claims and
downstream authority, durable research/workflow/outbox processing, CTI
investigation workflows and deterministic PCAP/PCAPNG evidence integration.
Packet-derived observables, content and semantic hashes, identities, rule
findings and non-attributive actor-overlap leads connect to investigation,
Navigator and reviewed report workflows.

Migration chains execute atomically. Fresh installations and existing schemas
are tested, and downgrades refuse to discard populated investigation metadata.
Back up PostgreSQL and evidence volumes before upgrading; follow the migration
and deployment guidance for the configured environment.

## Dependency and build maintenance

Updated Python, frontend, documentation and scanner dependencies; migrated
Tailwind 4; pinned the reviewed MalwareGraph source; refreshed Redis/Nginx base
packages and the Nuclei build toolchain. Security thresholds remain enforced.
Stable-distribution packages can retain unfixed upstream advisories: passing
release checks is not a vulnerability-free guarantee. The docs build includes
a documented locally maintained bounded-input braces mitigation.

## Deployment

The protected tag workflow publishes the nine-image Linux/AMD64 family and
attaches `adversarygraph-images.env` only after build, scan and public digest
verification. Deploy those immutable digests; shared `latest` tags do not move.
Historical beta tags remain immutable. Provider, semantic embedding, external
SIEM and operational integrations require deployment-specific acceptance; this
release does not imply that every optional external integration is configured.

Official ATT&CK release: https://attack.mitre.org/resources/updates/updates-october-2026/
