# AdversaryGraph v5.4.0 Release Notes

Release date: 2026-06-30

## Added

- Authenticated Observability dashboard for API uptime, request metrics,
  recent traces, top routes, redacted API log tails, and Prometheus-compatible
  metrics.
- Backend observability routes for summaries, traces, logs, and metrics.
- `make security-scan` and `scripts/security-scan.sh` for local lint, SAST,
  dependency, secret, Compose, and container checks where the required tools
  are installed.
- Bandit backend SAST coverage in CI.
- Screenshot-backed observability, security-scanning, authentication, Attack
  Simulation, CVE-correlation, and malware-analysis validation examples.

## Changed

- Corrected SAST findings involving weak hashes and XML parsing.
- Updated release metadata and release consistency checks for v5.4.0.

## Upgrade Notes

- Observability routes follow the deployment's authentication policy; verify
  monitoring credentials and reverse-proxy access rules after upgrading.
