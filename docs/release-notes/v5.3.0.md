# AdversaryGraph v5.3.0 Release Notes

Release date: 2026-06-30

## Added

- Native authentication and user-management workflows.
- A local `/auth-guide` page that remains available before sign-in.
- A direct authentication-guide link on the login page.
- Compose propagation for authentication bootstrap settings.

## Changed

- Updated authentication, quickstart, administration, security,
  production-readiness, and public-demo privacy documentation.
- Documented native username/password authentication, roles, bootstrap-admin
  cleanup, password reset, session behavior, and optional identity-aware
  reverse-proxy deployments.
- Updated release metadata and release consistency checks for v5.3.0.

## Upgrade Notes

- Review `.env.example` and the authentication guide before enabling native
  authentication in an existing deployment.
- Remove or rotate bootstrap administrator credentials after initial setup.
