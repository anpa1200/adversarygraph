# AdversaryGraph 8.1.2

Source date: 2026-10-20.

Opening Enterprise T1699 and switching to ICS previously retained the detail
panel and queried T1699 in the ICS catalog, producing a correct API 404 for
the wrong UI context. Technique panels now stay bound to their original
domain/version. Selected TTPs, overlays and expansion are retained per domain;
search/platform filters reset on catalog changes. Imported comments, scores and
tactic annotations survive switching away and back in the same Navigator view.
Copied technique links include domain and, when selected, catalog version.

The official ATT&CK v20 data was present: read-only comparisons of all 31,940
raw records across the three live domain snapshots matched the pinned official
bundles exactly. The active ID/name/subtechnique projection also matched. This
fix addresses UI state, not a missing MITRE data import. No database migration
or annotation rewrite is required.

Validation: TypeScript/Vite production build; seven focused Navigator/export
regressions; complete frontend suite (73 passed, four opt-in screenshot skips).
The normal CI and protected release workflow must pass before publication.

This integrated matrix does not provide every official MITRE Navigator feature.
Detection strategy/analytic/asset objects remain fully preserved in raw STIX,
while the technique panel exposes a reduced projection. Internal saved TTP
layers are ID selections; full annotated JSON round trips are a separate path.
See [8.1.1 release notes](v8.1.1.md) for the underlying stable line and security
limitations. Use only the complete published digest manifest for deployment.
