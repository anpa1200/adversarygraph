# AdversaryGraph v5.9.1 Release Notes

AdversaryGraph v5.9.1 adds **JA3/JA4+ network fingerprint IOC workflows** for
report extraction, IOC import, investigation pivots, and analyst review.

## Added

- JA3, JA3S, JA4, JA4S, JA4H, JA4L, JA4LS, JA4X, JA4SSH, and JA4T IOC types.
- Regex extraction for labeled JA3/JA4+ fingerprints in uploaded report text.
- Network fingerprint tagging and raw context preservation during IOC import.
- Network fingerprint context panel in IOC Detail.
- Network fingerprint labels and filtering in IOC Library.
- Network fingerprint node support in IOC node detail and IOC Investigation.

## Changed

- Labeled JA3 hashes are no longer treated as generic MD5 file hashes during
  report-text IOC extraction.
- IOC Investigation pivot scoring now treats network fingerprints as
  investigable observables for clustering traffic and infrastructure.
- VirusTotal lookup actions are hidden for network fingerprint observables
  because those values are not normal VirusTotal indicator lookups.

## Validation

- Version consistency script passes for v5.9.1 metadata.
- Frontend production build validates the updated IOC pages.

## Safety Boundary

Network fingerprints are clustering and correlation signals. They become
malicious only when source evidence, report context, or related observables
support that conclusion.
