# AdversaryGraph v5.2.0 Release Notes

Release date: 2026-06-30

## Changed

- Made backend tests reproducible in a clean shell by defining explicit
  test-safe `DB_PASS` and `LOG_DIR` defaults before settings import.
- Overrode Monaco's transitive DOMPurify dependency to a patched release,
  clearing the frontend audit finding without removing editor functionality.
- Added a shared frontend component-system foundation and migrated key
  workspaces to it.
- Fixed Debugger resizable-panel sizing.
- Updated release metadata across backend, frontend, README, roadmap, security
  policy, version matrix, and release checks.

## Validation

- Backend lint and tests with coverage passed.
- Frontend dependency audit and production build passed.

## Upgrade Notes

- No user action or breaking schema change is required for this QA release.
