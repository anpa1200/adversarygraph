# AdversaryGraph v5.8.0 Release Notes

AdversaryGraph v5.8.0 adds **Threat Radar**, a Product Security CTI early-warning
workspace for turning threat signals into scored cases, product exposure
mapping, and action workflows.

## Added

- Threat Radar sidebar route and Discover launchers.
- Threat source, signal, claim, evidence, entity, case, case-link, score,
  product-mapping, action, hunt, PSIRT, IR, detection, marketplace,
  supply-chain, report, and audit tables.
- Signal scoring from source reliability, claim credibility, product relevance,
  exploitability, exposure, and blast radius.
- Sanitized handling for legal-sensitive and restricted-source signals.
- Watchlists for CVEs, zero-day claims, supply-chain items, hardware, and
  marketplace-style signals.
- Case graph view for signals, CVEs, TTPs, products, components, dependencies,
  and case relationships.
- Action creation for PSIRT, Threat Hunt, IR escalation, and Detection
  Requirement workflows.
- Report generation for Flash Notes, Product Impact Assessments, Threat Hunt
  Packs, PSIRT appendices, and Executive Summaries.
- Threat Radar user guide and README documentation entry.

## Validation

- Frontend production build passes.
- Threat Radar backend route integration tests pass:
  - signal-to-case workflow;
  - legal-sensitive metadata sanitization;
  - watchlists and workflow queues.

## Safety Boundary

Threat Radar does not collect exploit payloads, stolen credentials, stolen data,
or illegal-source access instructions. Restricted-source intelligence must be
stored as sanitized metadata only and marked legal-sensitive where appropriate.
