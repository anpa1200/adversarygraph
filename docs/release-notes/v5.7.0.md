# AdversaryGraph v5.7.0 Release Notes

AdversaryGraph v5.7.0 adds a research collection workflow for source-backed
report review and report-to-platform entity linking.

## Added

- Reports / Research collection page for analyzed reports and research notes.
- Deterministic tag buckets for TTPs, IOCs, CVEs, threat actors, sectors, and
  infrastructure.
- Linked report review pages with inline links to Navigator, IOC Library, CVE
  Library, and ATT&CK Group Library.
- Source-text preservation for new AI analysis sessions so extracted mappings
  remain reviewable against the original report.
- Upload Research control with a `Parse with AI` checkbox.
- Store-only research upload path for analyst staging before LLM parsing.
- Research analysis guide for converting strategic embedded, hardware,
  firmware, edge-device, BMC, UEFI, GPU, SOHO/IoT, and OT/IoT research into
  AdversaryGraph workflows.

## Updated

- Discover and AI Analysis now link into the Reports / Research collection.
- The sidebar includes Reports / Research as a first-class workspace module.
- README and user guide link to the new research analysis guide.

- Ruff passed for the updated analysis route.
- `git diff --check` passed.
