# AdversaryGraph v5.1.0 Release Notes

Release date: 2026-06-30

## Added

- Source-correct telemetry requirements for Attack Simulation, including
  vendor/source-shaped event structures and explicit telemetry-gap reporting.
- Raw STIX preservation tables for all ingested objects and relationships,
  alongside the normalized ATT&CK query tables.
- CVE Library with NVD CVE API 2.0 and CISA KEV synchronization.
- Normalized CVE, CVSS, CWE, and CPE storage.
- Evidence-backed CVE relationships to ATT&CK techniques, IOCs, and actors.
- Telemetry-readiness details and updated ATT&CK/STIX and CVE data-model
  documentation.

## Changed

- Hardened AI Attack Assistant guidance around telemetry fidelity.
- Updated release metadata across backend, frontend, README, roadmap, security
  policy, and release consistency checks.
