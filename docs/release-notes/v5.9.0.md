# AdversaryGraph v5.9.0 Release Notes

AdversaryGraph v5.9.0 adds **EMB3D assessment workflows** and expands Threat
Radar with full asset-inventory import, product/component/dependency exposure
mapping, and asset review pages.

## Added

- EMB3D backend route and service for embedded-device threat model assessment.
- EMB3D frontend page and user documentation.
- Unified product, component, dependency, and asset model helpers for
  cross-module exposure analysis.
- Threat Radar full asset-inventory CSV template.
- Product-security example datasets for product, component, dependency SBOM,
  exposure, and asset inventories.
- Threat Radar asset review page for triaging product/component/dependency
  exposure.

## Changed

- Expanded Threat Radar and Asset Surface workflows to share richer inventory
  context across products, components, dependencies, exposures, and assets.
- Updated backend and frontend API clients for the new EMB3D and asset review
  surfaces.

## Validation

- Version consistency script passes for v5.9.0 metadata.
- EMB3D unit coverage added.
- Asset Surface and Threat Radar integration/unit coverage expanded for the
  asset workflow.

## Safety Boundary

EMB3D and Threat Radar workflows support defensive product-security assessment,
exposure triage, and detection planning. They do not collect exploit payloads,
stolen credentials, stolen data, or illegal-source access instructions.
