# AdversaryGraph v7.0.0 Release Summary

AdversaryGraph v7.0.0 is the isolated assessment, governed intelligence, and
data-quality release. It retains the evidence-to-detection workflows prepared
in v6.5 and promotes the completed post-v6.5 engineering work into a release
boundary with stronger service isolation, retrieval readiness, taxonomy,
catalog maintenance, self-test evidence, and artifact controls.

## What Changes for Analysts

- Asset analysts can run an explicitly authorized assessment against one exact
  saved-inventory target while the API, scanner tools, evidence, and AI review
  remain in separate trust boundaries.
- CTI analysts receive stronger relationship provenance and consistent actor,
  campaign, malware, tactic, TTP, and IOC taxonomy across retrieval, statistics,
  and graph workflows.
- Navigator, RAG, and MCP users receive database-backed readiness, safer
  incremental reconciliation, and the governed local AI adapter.
- Operators can use self-test data inventory to distinguish a technically live
  platform from one whose authoritative corpora are empty or incomplete.
- Release reviewers receive one eight-image build, scan, publication, and
  digest-manifest path that includes scanner MCP.

## Trust Boundary

The scanner service does not accept an arbitrary analyst URL or command. The
API resolves an exact target from stored asset inventory, authorizes the plan,
calls the private service with a dedicated capability, and verifies the target
and tool trace returned. The result is bounded evidence for analyst review.

AdversaryGraph remains advisory and evidence-preserving:

- it does not treat a discovered service or CVE candidate as a confirmed
  vulnerability;
- it does not execute hunt queries against external telemetry systems;
- it does not autonomously attribute an actor;
- it does not confirm Navigator proposals or save layers without analyst
  action;
- it does not let either MCP boundary bypass the application authorization
  model; and
- it does not make synthetic telemetry equivalent to real lab evidence.

## Product Scope

Version 7 retains 31 governed platform workspaces and adds the private scanner
MCP service as an application component. The generated v7 contract inventory
contains 323 OpenAPI operations and 288 frontend API call sites. These are
source-contract counts regenerated by the v7 release gate, not historical v6.5
figures or claims about runtime use.

## Release Evidence

The complete local gate is:

```bash
./scripts/release-readiness.sh --full
```

Immutable release acceptance additionally requires successful merge CI and the
protected `v7.0.0` tag workflow. That workflow must publish the exact eight
scanned images, verify public registry readability and image identity, create
the digest manifest, recheck the tag target and tag-protection rules, and create
the GitHub release from the v7 notes.
